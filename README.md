# Zarrouk Flowers Demo

Build a premium, elegant, modern website for a La Marsa flower shop called Zarrouk Flowers.

IMPORTANT:

This is a real local business.

Do NOT invent business information.

Do NOT invent prices, services, delivery policies, staff names, testimonials, awards, years of experience, certifications, partnerships, social-media handles, email addresses, opening hours, or claims about the business.

Any information that is not explicitly provided must be presented as editable placeholder content or omitted.

The website should feel like a professional website proposal/demo that could realistically be shown to the business owner.

OVERALL DESIGN

Create a luxurious floral boutique aesthetic.

Style:

Premium

Elegant

Warm

Sophisticated

Minimal

Editorial / boutique

Strong visual hierarchy

Lots of whitespace

High-end typography

Color palette:

Warm ivory / off-white background

Soft beige

Deep charcoal text

Muted sage/olive accents

Very subtle dusty rose accents

Avoid making the website overwhelmingly pink

Typography:

Elegant serif typography for major headings

Clean modern sans-serif for body text and navigation

Large editorial headlines

Refined letter spacing

The site should look expensive without looking complicated.

INTRO SECTION

Large editorial heading:

"Beauty, arranged naturally."

Short text:

"Flowers have a way of saying what words sometimes cannot. Discover a refined floral experience designed around beauty, emotion and the little details."

Keep this section visually minimal.

Use an elegant asymmetrical image/text layout.

COLLECTIONS SECTION

Heading:

"Explore the collection"

Create visually beautiful category cards.

Because the exact product catalogue has not been verified, use editable categories such as:

Bouquets

Roses

Seasonal flowers

Special occasions

Make every category easy to edit or remove.

Do NOT display prices.

Each card should have:

Large image

Category name

Short tasteful description

"Discover" link

Use realistic floral imagery, but make it clear in the code/content structure that images are replaceable with the business's actual photography.

Thank you

Celebration

Just because

These are general floral occasions and should not imply that Zarrouk Flowers specifically offers specialized packages for each one.

ABOUT SECTION

"Flowers with feeling."

Keep this section concise.

Do NOT invent the history of Zarrouk Flowers.

Then create a clearly editable text area where the actual business story can later be inserted.

Include a small note in the code/content structure:

Do NOT display that bracketed note prominently in the polished customer-facing version; make the section easy to edit from the source.
